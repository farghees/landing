# suggestion-replies

Codex-style suggested replies for Claude Code. After each answer Claude gives on the main thread, the mod asks the model (forking the session's own transcript, so it is cache-cheap) for three short follow-up replies in your voice and language, and shows them as buttons above the prompt. Press one (or its number key) to send it as your next message; ✕ dismisses them. They clear as soon as you submit anything.
